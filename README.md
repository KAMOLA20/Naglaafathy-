# منصة الأستاذة نجلاء فتحي التعليمية

منصة تعليمية متكاملة للغة العربية والرياضيات للمرحلة الابتدائية (الصفوف 1–6) وتأسيس رياض الأطفال، تتضمن شروحات صوتية ومرئية، متابعة المشاهدة، تقييمات الدروس، بوابة دفع ومحفظة، وتنبيهات المحاضرات ومحادثة مباشرة.

## التشغيل محلياً
```bash
npm install
npm run build
NODE_ENV=production node server.ts
```

## الرفع المجاني على Render (بعد الرفع على GitHub)
1. ارفع ملفات المشروع إلى مستودع GitHub.
2. في **Render.com** اختر **New → Blueprint** واختر المستودع (سيقرأ ملف `render.yaml` تلقائياً).
3. أضف متغير البيئة `DATABASE_URL` (من **Neon.tech** أو **Supabase** المجاني) لحفظ بيانات الطلاب دائماً.

راجع `DEPLOY_SERVER.md` لتفاصيل Docker وOracle VPS والربط مع Odoo.
